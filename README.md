# Vim Trainer · Vim 模式练习台

一个帮助 Vim 新手快速上手的 **闯关式练习平台**。它把真实编辑场景拆解成一个个循序渐进的任务，你在完成关卡的过程中自然掌握 Vim 的常用键位与操作模式，逐步建立起肌肉记忆。

## ✨ 功能特性

- **闯关式学习**：36 个关卡，按「基础 → 进阶 → 高级」循序渐进。
- **真实场景练习**：每个关卡都配有贴近日常编辑的示例代码与任务目标。
- **实时反馈**：内置 CodeMirror + Vim 键位仿真，实时记录按键、进度与完成状态。
- **速查表**：右侧常驻常用指令与 `Ex 命令`，随学随查。
- **无需构建**：纯前端静态项目，浏览器打开即可使用。

## 🎮 关卡体系

### 基础（21 关）

普通模式与方向键位、按词前进 `w`、按词后退 `b`、跳到词尾 `e`、行首与行尾 `0` / `$`、首个非空字符 `^`、单字符查找 `f`、进入插入 `i`、追加输入 `a`、下方新行 `o`、上方新行 `O`、删除字符 `x`、删除整行 `dd`、删除一个词 `dw`、修改一个词 `cw`、替换单字符 `r`、复制整行 `yy`、向后粘贴 `p`、向前粘贴 `P`、撤销 `u`、重做 `Ctrl-r`。

### 进阶（11 关）

重复上次修改 `.`、查找 `/`、反向查找 `?`、全局替换 `:%s`、可视字符选择 `v`、可视行选择 `V`、文本对象 `ciw` / `di"`、缩进 `>>`、反缩进 `<<`、跳到文件首尾 `gg` / `G`。

### 高级（4 关）

设置标记 `m`、录制宏 `q`、回放宏 `@`、保存与退出命令。

## 🚀 快速开始

### 方式一：直接用浏览器打开

双击项目目录下的 `index.html` 即可开始练习。

### 方式二：本地服务器（推荐）

```sh
python -m http.server 8000
```

然后在浏览器访问 `http://localhost:8000`。

> 使用本地服务器可避免部分浏览器对 `file://` 协议的限制。

## 🛠 技术栈

- HTML / CSS / JavaScript（纯前端）
- [CodeMirror 5](https://codemirror.net/)（编辑器 + Vim 键位仿真）
- [Lucide](https://lucide.dev/)（图标）
